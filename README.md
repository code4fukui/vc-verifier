# vc-verifier

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A command-line tool to verify the JWS signature of QR codes from Japan's COVID-19 vaccination certificate app.

This project was created to verify the QR codes generated by Japan's official [COVID-19 Vaccination Certificate Application](https://www.digital.go.jp/policies/posts/vaccinecert). These QR codes adhere to the international [SMART Health Card](https://smarthealth.cards/en/) standard, which uses a JSON Web Signature (JWS) to encode the data.

## How It Works

The script performs the following steps:
1.  Takes a raw QR code string (prefixed with `shc:/`) as input.
2.  Decodes the numeric string into a standard JWS format.
3.  Fetches the public JSON Web Key Set (JWKS) from the official issuer URL provided by Japan's Digital Agency.
4.  Verifies the JWS signature against the fetched public keys.
5.  Decompresses the JWS payload using zlib (DEFLATE).
6.  Prints the verified JSON payload, containing the vaccination details, to the console.

## Prerequisites

*   Node.js
*   Yarn

## Installation

```bash
yarn install
```

## Usage

Pass the full QR code string, including the `"shc:/"` prefix, as an argument to the `verify` script.

```bash
yarn verify <your_qrcode_string>
```

On success, the script will output the decoded and verified JSON payload.

## Technical Specifications

*   **Standard:** [SMART Health Card Framework](https://spec.smarthealth.cards/)
*   **Public Key Endpoint (JWKS):** `https://vc.vrs.digital.go.jp/issuer/.well-known/jwks.json`
*   **Core Dependencies:**
    *   [node-jose](https://github.com/cisco/node-jose) for JWS signature verification.
    *   [pako](https://github.com/nodeca/pako) for zlib DEFLATE decompression.
